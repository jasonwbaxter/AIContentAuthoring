## 🔄 Data Flow

### Page Load Flow
```
1. User visits http://localhost:3000
   ↓
2. Server checks language parameter (?lang=EN)
   ↓
3. Server reads /www/EN/ directory
   ↓
4. Builds navigation menu from files/folders
   ↓
5. Renders index.ejs with:
   - Title: "Central Bank"
   - Menu structure
   - Language switcher
   - Available languages
   ↓
6. Browser displays homepage
```

### Article View Flow
```
1. User clicks article in menu
   ↓
2. Browser requests /content/{lang}/{filename}
   ↓
3. Server reads .md file
   ↓
4. Converts Markdown to HTML
   ↓
5. Renders content.ejs with:
   - Article title
   - HTML content
   - AI Buttons (✨ 🎵)
   - Menu structure
   ↓
6. Browser displays article with AI features
```

### AI Feature Flow
```
User clicks "✨ Summarize with AI"
   ↓
JavaScript captures article content
   ↓
Sends POST to /api/summarize
   {
     "content": "Article text...",
     "language": "EN"
   }
   ↓
Server processes (ready for AI service integration)
   ↓
Returns summary
   {
     "summary": "Summary text..."
   }
   ↓
JavaScript displays summary in panel
   ↓
User can close panel with ✕
```

## 🔌 API Endpoints

### GET /
```
Request: GET http://localhost:3000/?lang=EN
Response: Homepage HTML
Features:
  - Menu for selected language
  - Language switcher
  - Available languages list
```

### GET /content/:lang/*
```
Request: GET http://localhost:3000/content/EN/Getting%20Started
Response: Article HTML with AI features
Features:
  - Article content (Markdown → HTML)
  - AI buttons
  - AI panels
  - Menu for selected language
```

### POST /api/summarize
```
Request:
{
  "content": "Article text to summarize",
  "language": "EN"
}

Response:
{
  "summary": "AI-generated summary..."
```
